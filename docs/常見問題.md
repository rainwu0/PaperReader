# 常見問題

## 1. PaperReader 會連網嗎？會把我的論文送出去嗎？

加入、閱讀、劃線、筆記、閱讀紀錄、匯出、備份與同步包都在手機上完成，不連網。只有你啟用的功能會連網：用你自己的帳號翻譯或產生重點筆記（每次送出前說明送到哪裡、你同意才送）、下載離線翻譯的語言模型與版面模型（下載前說明，不送出文獻內容）。沒有帳號、統計、追蹤或廣告。完整的清單在[隱私說明](privacy.md)。

## 2. 解除安裝 PaperReader，文獻會不見嗎？

看文獻庫放在哪裡（「設定 → 文獻庫 → 位置」）：

| 位置 | 解除安裝之後 |
|---|---|
| 共用空間（文件／PaperReader） | 文獻庫留在手機上。重新安裝、加入文獻時開啟權限，就會用回原本的文獻庫 |
| 應用專屬空間 | 文獻庫一併刪除。解除安裝前請先「匯出備份檔」 |

不論哪一種，應用的設定、翻譯服務的金鑰、術語庫都會刪除。

### 文獻庫在應用專屬空間，想搬到共用空間

「設定 → 文獻庫」的「搬到共用空間」（需要 Android 11 以上）：開「所有檔案存取」權限 → 確認搬去哪裡與要多少空間 → 等進度跑完。文獻、劃線、筆記、群組、回收區都會搬過去，應用專屬空間的舊資料搬完後刪掉；金鑰、設定與術語庫不受影響。

「文件／PaperReader」已經有文獻庫或別的檔案時不會搬。細節與各種情況見[安裝與第一次使用](安裝與第一次使用.md#之後想從應用專屬空間搬到共用空間)。

## 3. 首頁上方出現「檢查發現 N 個問題，文獻沒有被改動。」

應用每次打開都會檢查文獻庫，發現讀不懂或對不上的檔就列出來，例如某篇的描述檔讀不懂、原文的大小和記錄的不同（可能被別的工具改過）、資料夾裡有不認得的檔。按「查看」看每一項的說明。

檢查只列出問題，不會自動修改或刪除任何檔。檔案在別處改回來之後，按「再檢查一次」。

## 4. 首頁說「找不到文獻庫」或「原本的文獻庫不見了」

- **「沒有權限讀取文獻庫，文獻都還在。」**：「所有檔案存取」權限被關掉了。按「開啟權限」，在系統設定頁把開關打開再回來。
- **「原本位置的文獻庫不見了，文獻沒有被刪。」**：文獻庫資料夾被搬走或改名了。把它搬回畫面上寫的位置，再重新打開應用就會回來。按「在這裡建新的」會在原位置建一個空的文獻庫，不會動到別處的檔案。

## 5. 掃描的 PDF 可以用嗎？

可以閱讀、跳頁、用筆刷畫。掃描檔沒有文字層，所以選不到字、不能劃線（畫面會說「這一頁選不到文字（可能是掃描檔）。」），也不能翻譯或產生重點筆記。

## 6. 加入之後篇名或作者不對

篇名、作者、年份是從 PDF 自帶的資訊與第一頁讀出來的，有些 PDF 讀不準。打開那一篇的「文獻資訊」直接改篇名、作者、年份、DOI、網址，按「儲存」。

應用開著的時候，「整理文獻庫」會在手機上讀每篇原文，補上空著的 DOI、arXiv 網址與年份；已經有值的欄位不會被改掉。

## 7. 有些劃線「找不到原位置」

畫面說「N 條劃線找不到原位置，引句與短評仍在筆記。」，常見的原因是：

- 譯本 PDF 重新產生過，那幾段的譯文改了，劃線對不上新的文字。
- 原文 PDF 在應用以外被換成另一個版本。

劃線的引句與短評都還在筆記窗格與筆記檔裡，不會遺失。

## 8. 翻譯失敗了

| 畫面說的 | 通常是 | 怎麼辦 |
|---|---|---|
| 服務不接受這把金鑰。 | 金鑰貼錯，或帳號沒有權限、沒有餘額 | 到「設定 → 產生 → 翻譯服務」重新貼金鑰，按「測試服務」確認 |
| 這個帳號的額度用完了。 | 金鑰沒問題，額度用完 | 額度重置或加購之後按「接著翻」，或改用備用服務 |
| 服務暫時不接受，稍後再接著做。 | 呼叫太頻繁 | 稍後再接著翻；常發生時在服務設定調低「每分鐘最多幾次請求」 |
| 連不上服務。 | 沒有網路，或服務網址不對 | 確認網路與服務網址 |
| 還沒下載語言模型。 | 選了離線翻譯，模型還沒下載 | 在翻譯面板或「設定 → 產生」下載 |

已經翻好的段落都存著，不會因為失敗而不見。

## 9. 移除的文獻去哪裡了？

「移除這篇文獻」會把它移到回收區，可以還原；剛移除時畫面上也會出現「復原」，按了馬上放回。

- 回收區在「設定 → 文獻庫 → 回收區」，按「還原」放回目錄。
- 在回收區按「永久刪除」或「清空回收區」，檔案會刪掉，無法復原。這篇的筆記檔留著。
- 從文獻資訊移除的一份譯本或重點筆記，也一樣放進回收區，可以還原。

## 10. 有全文搜尋、電腦版、自動同步嗎？

全文搜尋有：首頁搜尋框下面的「內文」一節找得到原文、譯文、你的短評與筆記裡的字句，點了開到那一頁並框出來，不連網。剛加入的論文要等應用在背景抽完文字才找得到。

這一版還沒有：

- 只有 Android 版。電腦版（Windows 先做）開發中。
- 兩台之間要手動搬同步包（見[備份與同步包](備份與同步包.md)），還沒有自動同步。

文獻之間的連結已經有了：點正文的引用編號看那一條、在「文獻資訊」看這篇引了庫裡哪幾篇，見[閱讀與劃記](閱讀與劃記.md#文獻之間的連結)。

## 11. 裝新版時顯示「套件無效」，裝不上

新版直接裝在舊版上就是更新，資料都會保留；有少數手機會顯示「套件無效」。可以這樣做：

1. 先確認下載的是對的檔：大部分手機是 `PaperReader-版號-arm64.apk`，檔案大小和發布頁上的相同（不完整的下載也會顯示「套件無效」）。
2. 還是裝不上時，先看[第 2 題](#2-解除安裝-paperreader文獻會不見嗎)：文獻庫在「文件／PaperReader」（共用空間）的話，解除安裝舊版不會刪掉文獻、劃線與筆記，再裝新版、指回同一個位置就好；翻譯金鑰與設定要重新填。文獻庫在應用專屬空間時，先到「設定 → 文獻庫」搬到共用空間或匯出備份，再解除安裝。
3. 方便的話到 GitHub 回報手機型號與系統版本，幫我們找出原因。

從 0.1.1 起可以在應用裡更新（設定 → 關於 → 檢查更新），不必再自己下載安裝。

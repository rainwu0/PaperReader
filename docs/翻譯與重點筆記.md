# 翻譯與重點筆記

PaperReader 可以把一篇文獻翻成譯本，也可以請 AI 整理成重點筆記。這兩件事都是選用的：不設定任何服務，閱讀、劃線、筆記照樣完整可用。

## 先決定用哪一種方式翻

| 方式 | 要準備什麼 | 論文的文字會不會離開手機 | 費用 |
|---|---|---|---|
| 離線翻譯（Firefox 翻譯） | 下載一次語言模型（約 34 MB） | 不會 | 免費 |
| 你自己的翻譯服務帳號 | 一把服務的金鑰 | 會，送到你選的服務 | 照那家服務的價格，算在你自己的帳號 |
| 別處做好的譯本 | 一份譯本 PDF | 不會 | — |

離線翻譯只有英文譯成繁體中文、簡體中文兩種。要翻成別的語言，或想要對話模型的譯文，就用自己的帳號。

## 設定翻譯服務

到「設定 → 產生 → 翻譯服務」。清單裡每一種服務一筆，預設啟用的是 Claude 與 Firefox 翻譯，主要服務是 Firefox 翻譯（離線，第一次用時下載模型）；開關打開的服務才會出現在翻譯面板。

| 服務 | 種類 | 金鑰去哪裡拿（各家的頁面名稱會變） |
|---|---|---|
| Claude（Anthropic） | 對話模型 | Anthropic 的開發者主控台，建立 API 金鑰 |
| OpenAI | 對話模型 | OpenAI 的開發者平台，建立 API 金鑰 |
| Gemini（Google） | 對話模型 | Google AI Studio，建立 API 金鑰 |
| 自訂端點（OpenAI 相容，含 Ollama） | 對話模型 | 你自己架的服務。本機端點通常不需要金鑰 |
| DeepL | 機器翻譯 | DeepL 帳號裡的 API 金鑰。免費方案的金鑰會自動連到 DeepL 的免費網址 |
| Google Cloud 翻譯 | 機器翻譯 | Google Cloud 主控台：啟用 Cloud Translation API，再建立 API 金鑰 |
| Firefox 翻譯（離線） | 在這支手機上翻 | 不需要金鑰 |

點進一個服務可以設定：

| 欄位 | 說明 |
|---|---|
| 金鑰 | 貼上之後按「儲存金鑰」。金鑰只存在這支手機上，用 Android 的金鑰庫加密，不會進文獻庫、備份檔或任何記錄。存好之後畫面只顯示遮罩 |
| 模型名稱 | 對話模型可以填。留空用預設，例如 Claude 是 `claude-sonnet-5-5`、OpenAI 是 `gpt-4o-mini`、Gemini 是 `gemini-2.5-flash`；自訂端點一定要填 |
| 服務網址 | 留空用官方網址；自訂端點一定要填，例如 `http://電腦的網址:11434/v1/` |
| 每分鐘最多幾次請求 | 服務常回「太頻繁」時調低。留空是不限 |
| 單價（美元／百萬詞元） | 只用來粗估花費，照服務的價目表填輸入與輸出的單價。不填就只顯示詞元數 |
| 測試服務 | 送一句固定的英文短句，顯示送出什麼、收到什麼、花了幾秒。不含你的論文 |

服務網址是 `http://`（不加密）而且不在本機或私人網段時，畫面會警告：金鑰與文字會以明文送出。

### 主要服務與備用服務

清單上方的「主要與備用」可以排順序。主要服務連不上、額度用完或一直被限速時，應用會先問你要不要改用下一個備用服務，並說明剩下的段落會送到哪裡；你同意才換。金鑰不對時不換。

### 費用

用你自己的金鑰時，費用由那家服務直接向你的帳號收。PaperReader 不經手、不加價。

- 每次翻完或產生完，「用量」寫出這次與這篇累計的輸入、輸出詞元數；服務設定裡填了單價，會加上粗估的美元金額。
- 翻譯面板的「第二輪潤飾」會在譯完之後再請模型修順一次，費用約加倍。
- 實際金額以服務的帳單為準。

## 翻譯一篇

1. 在閱讀畫面按工具箱的「產生」，或在「文獻資訊」按「產生譯本」。最上面選「譯本」。
2. 在翻譯面板選：
   - **原文**：「自動判斷」或指定語言。
   - **翻成**：目標語言。
   - **翻譯服務**：啟用的服務之一。
   - **提示詞預設組**：只對對話模型有效，見後面「提示詞預設組」。
   - **第二輪潤飾**：要不要多修一次。
3. 用你的帳號時，面板寫明「每一段的文字（不含圖片、筆記與劃線）會送到」哪個服務。勾「我同意把這篇的文字送到 …」，再按「開始翻譯」。用離線翻譯時，面板寫「不送出任何東西。」
   - 離線翻譯的語言模型還沒下載時，按鈕是「下載模型並翻譯（約 34 MB）」。按下去先說明從哪裡下載、多大，按「下載」才下載；下載中可以停。下載完自動開始翻譯。下載途中離開面板或換了服務，就不會自動開始。
4. 進度畫面先分析版面，再逐批翻譯。可以離開這個畫面，翻譯會繼續。
5. 全部翻完之後，應用自動排出一份版面和原文相同的譯本 PDF。按「開啟譯本」就能看。

翻譯中途停下或取消，翻好的段落都存著。再打開翻譯面板會看到「這篇已經有一份譯本」與「接著翻」，只翻還沒翻好的段落。

### 送出前詢問

每一次要把論文文字送出手機，面板都會說明送到哪裡，等你同意才送。不想每次都勾，可以在同意那一行旁邊勾「之後不再詢問」，或在「設定 → 產生」打開「送出前不再詢問」。換備用服務時仍會先問。

### 翻好之後可以怎麼看

| 看法 | 在哪裡 | 適合 |
|---|---|---|
| 譯本 PDF | 工具箱「譯本」 | 和原文同一個版面，可以劃線、用筆刷 |
| 原頁疊譯文 | 長按工具箱「譯本」，選「原頁疊譯文」 | 在原文頁面上直接看譯文，點一段暫看原文 |
| 譯文 | 工具箱「譯文」 | 排成手機好讀的文字，有目錄、可調字級 |

在「譯文」裡：

- 點一段，可以看那一段的原文。
- 長按一段可以就地改譯文，或點一段後按「改」。改過的段落標「已改」，之後接著翻、重新翻譯都不會蓋掉它。
- 改過譯文之後，畫面會提醒「譯文改過了，譯本 PDF 還是改之前的。」，按「更新譯本 PDF」重排。
- 「看版面」回到 PDF 的同一段。
- 右上角的選單有「字級」與「檢查譯文」。

### 檢查譯文

「檢查譯文」是核對用的：

- 一段原文配一段譯文。自動檢查比對了數字、引用、公式與網址，可能有問題的段落會標出原因，可以「只看這些段」。
- 「這篇的術語」：翻譯時兩批都用同一個譯法的術語會定下來，之後的批次與這篇的重點筆記照用。看得到、改得了、刪得掉；已翻好的段落不會自動重翻。
- 「比較這段」「比較這頁」：選兩到三個服務各翻一次並排比較，按「用這個」套用。這會把那幾段送到你選的服務，送出前一樣要同意。
- 匯出給翻譯軟體：XLIFF 2.1（給 Trados、memoQ、OmegaT）或 TMX 1.4b。

### 重新翻譯

翻譯面板下方的「重新翻譯」會另做一份新的譯本與譯本 PDF；目前這一份和上面的劃線、筆跡都留著。不要的那份可以在「文獻資訊」的材料清單移除，它會放進回收區，可以還原。

### 加入別處做好的譯本

翻譯面板的「加入別處做好的譯本檔」，或「文獻資訊」的「加入譯本」，可以選一份 PDF 當這篇的譯本。它會出現在「要看哪一份」裡，標成「譯本（自己加入的 PDF）」。

### 譯本 PDF 的限制

- 含行內公式的段落、沒翻好的段落，在譯本 PDF 上保留原文；完整的譯文在「譯文」裡看得到。
- 太長、放不下的段落會縮小字級，再放不下時後面會被截掉，完成時畫面會說幾段。
- 掃描版 PDF 沒有文字層，沒辦法翻譯，畫面會說「沒有可以翻譯的文字（可能是掃描版）。」
- 分段由應用自動判斷，不一定每一段都切得對。下載版面模型可以切得更準（下一節）。

## 下載與刪除模型

有兩種模型要另外下載。都是你按了才下載，下載前會說明從哪裡下載、多大，而且不送出任何文獻內容。

| 模型 | 做什麼 | 從哪裡下載 | 大小 | 在哪裡管理 |
|---|---|---|---|---|
| 語言模型 | 離線翻譯（Firefox 翻譯）用，英譯繁中、英譯簡中各一個 | Mozilla 的內容傳遞網路 | 各約 34 MB | 「設定 → 產生 → 離線翻譯模型」（列上寫著下載了沒有、多大，點了到 Firefox 翻譯的服務頁）；也可以在翻譯面板按「下載模型並翻譯」，或在選字的快速翻譯卡片上按「下載模型」 |
| 版面模型 | 只用來把譯本分段分得更準；沒下載時照現行的方式 | Hugging Face | 約 124 MB | 「設定 → 產生 → 版面模型」 |

- **下載**：按「下載模型」，看過說明再按「下載」。下載中可以按「停止下載」，停下來不會留下半個檔。
- **只在 Wi-Fi 下載**：Firefox 翻譯的服務頁有「只在 Wi-Fi 下載模型」，兩種模型都照這個設定；翻譯面板與快速翻譯卡片上的下載也照它。
- **選字的快速翻譯**：快速翻譯用的是 Firefox 翻譯而模型還沒下載時，卡片上會說明並給「下載模型」。下載完，卡片還開著就接著翻選的那一段。
- **刪除**：按「刪除模型」，確認之後刪掉。刪掉版面模型之後，之後的譯本照現行的方式分段；已經做好的譯本不受影響。
- 版面模型下載之後，翻譯的進度會多一步「正在用版面模型分段…」。它在手機上執行，不連網。重點筆記不用它。

## 提示詞預設組

「設定 → 產生 → 提示詞預設組」決定對話模型「要做什麼、怎麼寫」。機器翻譯與離線翻譯不用提示詞。

- 上方切換用途：「翻譯」或「重點筆記」。
- 內建的有翻譯用的「通用」「學術論文」與重點筆記用的「標準」。可以直接改（標「已改」），也可以「還原預設」。
- 「複製一份」或「新增預設組」做自己的。可用的變數：`{{from}}` 原文語言、`{{to}}` 目標語言、`{{title}}` 篇名。
- 回覆的格式、段落代號、保留公式與引用、臺灣用語與全形標點、術語這些部分由應用固定加上，不必寫進提示詞。
- 「看完整提示詞」以一段範例原文為例，原樣列出實際會送出的內容，固定的與可改的部分分開標出。
- 重點筆記的預設組另有「區段」：每個區段一個標題，最多 12 個，各自寫「要寫什麼」與「最多幾點」。

翻譯面板與重點筆記面板都可以臨時換一組，也可以從面板直接到設定頁編輯那一組。

## 術語庫

「設定 → 產生 → 術語庫」指定術語的譯法，例如 `token` 一律譯成「詞元」。

- 「加一條」：原文詞、譯法、備註（可不填）。
- 「匯入 TSV」「匯出 TSV」：三欄 TSV（原文、譯法、備註），OmegaT 與 DeepL 都讀得懂。
- 翻譯時只把那一段原文裡出現的術語交給對話模型。
- DeepL 也會套用術語庫，但要在翻譯面板選定原文語言。
- 術語庫存在這支手機上，不進文獻庫，所以不在備份檔與同步包裡。換手機時請先「匯出 TSV」。

## 重點筆記

重點筆記是 AI 依區段整理的一篇文獻的重點，每一點附原文頁碼，點了回到那一頁核對。它用的是「翻譯服務」清單裡的對話模型（Claude、OpenAI、Gemini、自訂端點），機器翻譯與離線翻譯不能做重點筆記。

### 產生

1. 在閱讀畫面按工具箱的「產生」，最上面選「重點筆記」；或在「文獻資訊」的「重點筆記」按「產生重點筆記」。
2. 面板寫明用哪種語言寫（跟著翻譯的目標語言）、用哪個服務、哪一組提示詞，以及「論文的文字會送到」哪個服務。勾同意，再按「開始產生」。
3. 進度依序是讀原文、分部分整理、合併各部分。可以離開這個畫面，做好會自動存進文獻庫。

完成時畫面寫「已存好：N 點。」。對不上原文段落的點會被略過，畫面也會說幾點。這篇已經有重點筆記時，預設是新的做好之後取代舊的，舊的移到回收區、可以還原；勾「另外做一份新的」則兩份都留著。

### 看與核對

從「文獻資訊」的「看重點筆記」，或長按工具箱「譯本」選「重點筆記」打開。

- 頂端寫著用哪個服務、哪天做的，以及「AI 產生，未校對」。核對過之後按「標為已校對」。
- 每一點下面有頁碼（例如「p. 6」），點了跳到原文那一頁。
- 不要的點，按它右下角的刪除鈕（「刪掉這一點」），確認後就從檔案裡拿掉。
- 「用其他應用打開」「匯出」把它交給別的應用或存成檔案。
- 首頁的篩選有「有重點筆記」，列上也會標出。

### 檔案

重點筆記存成那篇資料夾裡的 `digest.md`，是一般的 Markdown 檔。Obsidian 等筆記工具打得開、能改字；回到 PaperReader 重新打開重點筆記，就讀到改過的內容。每一點行尾有一段 `<!-- paperreader:point … -->` 標記，不要改它。

各服務的名稱與商標屬於各自的公司。PaperReader 與這些公司沒有關聯。

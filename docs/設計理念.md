# 設計理念

PaperReader 是給研究者的文獻閱讀器：方便閱讀、筆記、紀錄。這份文件說明它為什麼長成現在這樣，以及哪些事它刻意不做。

## 為誰做

以讀論文為日常工作的人：研究生、博士後、教師、業界的研發人員，一個人工作。讀的多半是外文、雙欄、有公式與圖表的論文 PDF；零碎的時間用手機讀，寫作與多工用電腦。手上一定有一台裝置，可能有筆記工具、雲端硬碟、模型服務的帳號，但每一樣都可能沒有。在意的是：資料是自己的檔案、搬得走、不被某個服務綁住；讀到哪、記了什麼不會不見。

判斷一項功能要不要做、怎麼做，用一個問題檢驗：**只有一台裝置、其他什麼都沒有的人，用起來是不是完整的？**

## 四個原則

### 1. 資料是你的檔案

文獻庫是裝置上一個看得到的資料夾，裡面是一般的檔案：原文 PDF、譯本、描述檔（JSON）、筆記（Markdown）、閱讀紀錄（一行一筆的 JSON）。

- **沒有藏起來的資料庫**。目錄與搜尋為了加快速度建的索引放在應用自己的空間，隨時可以從文獻庫的檔案重建；刪掉它不丟任何資料。
- **格式公開、有版本號**，固定的檔名與欄位用英文（見[文獻庫格式](格式/文獻庫.md)）。應用壞了、不用了，資料照樣讀得到。
- **和別的工具共用同一個資料夾**。檔案管理員、Obsidian、同步工具可以直接讀寫。應用認文獻靠描述檔裡的代號，不靠檔名；檔案在外面被改過，應用讀到新的內容，不蓋掉外面的修改；不是應用寫的檔，它不刪、不改名、不覆寫。
- **不丟、不壞排第一**。寫入時先寫暫存檔再換上去，中途被強制結束不會留下半個檔；移除先放回收區；檢查文獻庫時只列出問題、不自動修；兩處同時改時不覆蓋，請你決定。

### 2. 一台裝置就完整

加入、閱讀、劃線、筆記、閱讀紀錄是**基本功能**：只需要一台裝置，不需要網路、帳號、另一台機器或雲端空間。

需要額外資源的能力是**擴充**，有那項資源的人才加上：用自己的帳號翻譯、在兩台裝置之間同步、日後接自己的雲端空間或主機。擴充不影響基本功能，沒有它時畫面上就是不顯示或寫「還沒有」，不是壞掉。

手機重隨身閱讀與手寫，電腦重多工。兩者都可以是唯一的裝置；第二台是加上去的，不是前提。

### 3. 產生的方法可以換

翻譯與重點筆記是讀外文論文的重要輔助，但應用不綁定某一個工具或某一個模型：

- 應用定的是**產出的格式**（譯文疊加檔、譯本 PDF、重點筆記），不是用哪個引擎。現在接得上幾家對話模型、兩家機器翻譯、你自己架的相容端點，以及在手機上執行的離線翻譯。
- 在別處做好、照格式放進來的譯本，也能直接對照。
- 用的是**你自己的帳號與金鑰**，費用在你的帳號，送出前先問。
- 讀的人不完全信任 AI 的產出，所以產出要**能回到原文核對**：譯本和原文同一個版面、切換時停在同一處；重點筆記每一點帶頁碼，點了回到那一頁；AI 產生的內容標「未校對」，由你標示已校對。核對不另設功能區，靠「帶頁碼就能點回原文」這條性質做到。

### 4. 新功能以外掛加上

新的功能做成可以整個拿掉的模組（外掛）：

- 外掛編譯進安裝檔，不從外面載入程式碼。
- 外掛只經由應用核心公開的操作讀寫文獻庫，和其他部分遵守同一套規則。
- 外掛要留下的資料，屬於你的就存成文獻庫裡格式公開的檔案；能重建的放索引。拿掉外掛之後，它留下的檔案原封不動、仍然讀得到。
- 外掛要連網時，同樣先說明連到哪裡、送出什麼，你同意才連。

第一個外掛是文獻之間的連結：從一篇的參考文獻找到文獻庫裡的另一篇。它在手機上抽出參考文獻、比對文獻庫，不連網；你的判斷（是這篇、不是這篇、指定）存成那一篇資料夾裡格式公開的 `references.json`。

## 取捨時的順序

兩件事衝突時，前面的優先：

| 順位 | 目標 | 意思 |
|---|---|---|
| 1 | 你的資料不丟、不壞 | 任何情況下不弄壞文獻庫；不動不是應用寫的檔案 |
| 2 | 資料是你的，離線完整可用 | 檔案為準、格式公開、搬得走；基本功能不需要網路與別的機器 |
| 3 | 在所用的裝置上好讀、好操作 | 手機一手可操作；等待有回應，出錯說人話 |
| 4 | 接手的人改得動 | 文件與程式讀得懂，改得安全 |
| 5 | 做法換得掉、功能接得上 | 備份、同步、產生的方法可以替換；新功能以外掛接上 |

## 不做什麼

- **不取代筆記軟體**。應用負責閱讀當下的筆記，筆記始終是你的筆記工具打得開的 Markdown 檔，深入的整理交給你慣用的工具。
- **不是多人協作的服務**。每個人用自己的文獻庫；沒有共用空間與權限，基本功能不需要帳號。
- **不是書目管理軟體**。可以匯出書目檔與引用格式，但主要需求是管理書目的人，不是這個應用的對象。
- **不靠檔名猜內容**。別處的資料要經過匯入轉成應用的格式，應用不為了配合某種既有的資料夾慣例加特例（整批匯入用一份公開格式的清單，見[匯入清單](../規格/04_匯入清單.md)）。
- **不收集使用資料**。沒有統計、追蹤、廣告或當機回報（見[隱私說明](privacy.md)）。

# 隱私說明

[English](privacy.en.md) · **繁體中文**

PaperReader 把你的資料放在你自己的裝置上。基本功能完全不連網；只有你啟用的翻譯、重點筆記、模型下載與檢查更新會連網，而且每一種連網用途都先說明、你同意才連。本文件列出應用實際會連到哪裡、送出什麼。

## 資料存在哪裡

- 文獻庫是你裝置上的一般資料夾與檔案（Android 上預設在 `Documents/PaperReader`）：論文 PDF、譯本、重點筆記、劃線、筆跡、筆記（Markdown 檔）、參考文獻清單、閱讀紀錄。你可以用檔案管理員或別的工具直接開啟。
- 應用的設定、翻譯服務的設定、提示詞預設組與術語庫放在應用專屬空間，不在文獻庫裡；解除安裝時一併刪除。
- 備份檔與同步包是你主動匯出的檔案，放在你選的位置，由你自己搬運。它們是沒有加密的 zip，裡面有文獻庫的內容（論文、筆記、劃線、閱讀紀錄）；拿到檔案的人都打得開，請像保管文獻庫本身一樣保管它們。金鑰與應用的設定不在裡面。
- 應用關閉了 Android 的系統備份與換手機搬移：你的文獻庫不會在你不知情時被傳到雲端。
- 本專案沒有自己的伺服器，沒有帳號系統。

## 什麼時候會連網

| 用途 | 連到哪裡 | 送出什麼 | 先同意嗎 |
|---|---|---|---|
| 線上翻譯 | 你選的翻譯服務：Anthropic（`api.anthropic.com`）、OpenAI（`api.openai.com`）、Google Gemini（`generativelanguage.googleapis.com`）、DeepL（`api.deepl.com`，免費版金鑰為 `api-free.deepl.com`）、Google Cloud Translation（`translation.googleapis.com`），或你自己填的相容端點（例如你自己架的 Ollama） | 要翻的段落文字、翻譯指示（目標語言；有設定術語庫時，術語；對話模型另加你選的提示詞預設組與這篇已定的術語譯法）、為了前後文連貫而附的前一段文字，以及你的金鑰。不含圖片、筆記與劃線 | 是。每次送出前會顯示會送到哪個服務、送什麼，你同意才送；你可以在設定裡改成不再詢問。換到備用服務時一律先問 |
| 比較翻譯服務（檢查譯文裡） | 你選的兩到三個翻譯服務 | 那一段或那一頁的段落文字與翻譯指示，以及各自的金鑰 | 是。每次送出前顯示會送到哪些服務 |
| 產生重點筆記 | 你選的對話模型服務（同上表的 Anthropic、OpenAI、Gemini 或相容端點） | 論文的文字、你選的提示詞預設組、術語庫與這篇已定的術語譯法，以及你的金鑰 | 是。每次送出前顯示會送到哪個服務，你同意才送 |
| 測試服務（設定裡） | 你設定的翻譯服務 | 一句固定的英文短句，加上你的金鑰；不含你的論文 | 你按下測試才會送 |
| 下載離線翻譯模型 | Mozilla 的內容傳遞網路 `firefox-settings-attachments.cdn.mozilla.net` | 只是下載檔案的請求，不含你的論文或資料；下載的是模型（約 34 MB），下載後會驗證檔案的雜湊值 | 是。使用前會說明連到哪裡、多大，你同意才下載 |
| 下載版面模型（設定 → 產生） | Hugging Face 上 PaddlePaddle 官方的模型頁 `huggingface.co`，它會轉到 Hugging Face 自己的內容傳遞網路（`*.hf.co`） | 只是下載檔案的請求，不含你的論文或資料；下載的是模型（應用顯示約 124 MB），下載後會驗證檔案的雜湊值 | 是。使用前會說明連到哪裡、多大，你同意才下載 |
| 檢查更新（Android；設定 → 關於 → 檢查更新） | GitHub 的 API `api.github.com`，問本專案（`rainwu0/PaperReader`）的發布清單 | 一個不帶任何資料的請求；GitHub 看得到你的 IP 位址與應用名稱（`PaperReader-update-check`），不含版本、裝置或你的資料 | 是。預設關；第一次會說明連到哪裡、送什麼，你同意才查。之後打開應用時一天最多查一次，可以在同一頁關掉自動檢查，或收回同意（收回後一個請求都不送，查到的版本與下載的檔一起刪掉） |
| 下載更新 | GitHub 的發布頁 `github.com`，它會轉到 GitHub 的檔案主機（目前是 `release-assets.githubusercontent.com`）。應用只跟著轉到 https 的 `github.com`、`api.github.com` 與 `*.githubusercontent.com`，轉到別處就停 | 只是下載檔案的請求：這台手機架構的安裝檔與核對碼清單 `SHA256SUMS.txt`，帶的標頭和檢查更新一樣（應用名稱），轉址時不帶來源網址（`Referer`）。下載後核對 SHA-256，並確認安裝檔是用和已安裝的同一把簽章金鑰簽的，不符就刪掉 | 是。查到新版後你按「更新」才下載；用行動數據時先說大小 |

沒有列在上面的，就不會連網。具體來說：

- 加入、閱讀、劃線、筆記、閱讀紀錄、匯出、備份與還原、匯出與匯入同步包都在裝置上完成，不連網。
- 離線翻譯下載完模型之後，翻譯在裝置上進行，不送出論文內容。
- 版面模型只用來把要翻譯的論文分段分得更準，在裝置上執行，不送出論文內容。
- 「整理文獻庫」在裝置上讀每篇原文，補上 DOI、arXiv 網址與年份，並抽出參考文獻清單；只在這台裝置上比對，不連網，也不查詢任何書目服務。
- 應用不會載入外部的字型、腳本或圖片；PDF 閱讀用的元件都隨安裝檔內含。
- 不使用統計、追蹤、廣告或當機回報，沒有帳號，不收集使用資料。

| 網路 | 上面「什麼時候會連網」那張表的用途 | — |

## 金鑰

翻譯服務的金鑰是你自己的帳號與額度。金鑰用 Android Keystore 產生的金鑰加密後，存在應用專屬空間，不放在設定檔、不放進文獻庫、備份檔或同步包。金鑰只會送給你選的那個服務。

## 你的翻譯服務如何處理資料

論文文字一旦送到你選的服務，就適用那家服務的隱私政策與資料使用條款，PaperReader 無法控制。若論文不能外傳，請改用離線翻譯，或用你自己架的本機端點。

## 如果你使用 `http://` 的服務網址

網址若是 `http://`（不加密）而且不是本機或私人網段，金鑰與論文文字會以明文送出；應用會警告你，請改用 `https://`。
